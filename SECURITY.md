[# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported.

| Version         | Supported          |
| --------------- | ------------------ |
| `main` (latest) | :white_check_mark: |
| Older / forks   | :x:                |

## Reporting a Vulnerability

The main "vulnerability" for this project is **detection** — anything that lets
a game identify, flag, or trace GcViewerV3 while it's running.

If you find a detection vector, report it privately:
- **Do Open** a public issue if you like.
- Use **GitHub Security Advisories** (Security tab → "Report a vulnerability"),
  or contact [@awakenkn](https://discord.gg/KJGymYKM7a) directly.

Include what's detectable, how to reproduce it, and the affected file(s).

You'll get a response within a few days, and confirmed issues will be patched
on `main` as soon as possible.](https://discord.gg/KJGymYKM7a)
