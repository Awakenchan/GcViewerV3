# Contributing to GcViewerV3

Thanks for your interest in contributing!

## How to contribute
- **Bugs:** Open an issue with steps to reproduce and your environment.
- **Features:** Open an issue to discuss before submitting a PR.
- **Pull requests:** Keep them focused, explain what changed and why.

## Guidelines
- Match the existing code style.
- Test your changes before submitting.
- One feature/fix per PR.

## Questions
Open an issue or check the [docs](https://gcviewer.gitbook.io/gcviewer-docs).
